# Security policy

## Reporting a vulnerability

Please do not report a security vulnerability in a public issue, pull request or discussion.

Report it privately instead: go to the **Security** tab of this repository and choose
**Report a vulnerability** (GitHub private vulnerability reporting).
Include what you found, the steps to reproduce it and the impact you expect.

You can expect a first reply within a few working days. We will keep you informed
while we investigate and fix the issue.

## Supported versions

VocabMaster has no versioned releases. Only the latest code on the `main` branch is supported;
fixes are made there.
